## 亮点与局限

- 用平面印刷海报的构图与配色表现送件场景：白色鹈鹕、金黄色长嘴、青绿色车架，以及赭黄色和粉色建筑。
- 自行车与鸟的轮廓以 SVG 绘制；页面无需构建，也不依赖外部图片、字体或网络请求。
- 车轮以 CSS 旋转；JavaScript 让脚掌跟随踏板，并更新腿部的二次曲线路径。两者采用约 2.5 秒一圈的装饰性骑行节奏，遵循系统的减少动态效果偏好。
- 造型采用风格化比例。动画不模拟真实骑行动力学，腿部动作也不是生物力学复现。
