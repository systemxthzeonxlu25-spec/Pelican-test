## ✨ 亮点

- **腿是算出来的**：两段式 IK，已知髋关节和踏板位置实时解出膝盖，踩到底时腿基本伸直，踩到顶时屈膝，脚掌还会跟着踏频微微上下翻（ankling）
- **传动是真的**：牙盘 22、飞轮 13，后轮转速按齿比算；链条是两个齿盘的外公切线加包角圆弧，链节的流动速度等于牙盘线速度
- **视差都从车轮推**：车轮滚过的路程驱动整个场景，对岸的山、海面反光、海堤砖缝、路面、草丛按远近用不同速度平移，山的轮廓用周期能整除 800 的正弦叠出来，循环没有接缝
- **白鹈鹕的细节**：黑色飞羽、淡黄冠羽、眼周橙色裸皮、喙尖带钩，喉囊半透明，里面揣着一条会扭的鱼
- **一点戏**：被风吹起的开叉围巾、认真的眉毛、随踩踏起伏的身体和点头、偶尔眨眼、对岸灯塔会闪

## 🤕 翻车点

- **腿太长**：真鹈鹕腿很短，为了够得着踏板，大腿和小腿都拉长了，乍一看有点像穿了白色紧身裤
- **灯塔比例不对**：本该是对岸远处的小灯塔，画得偏大，转到车头附近时看起来像立在车把旁边
- **草丛像箭头**：路边那排草丛画成了向下的箭头，像在给鹈鹕指路
- **翅膀当手**：翼尖直接攥住车把，解剖上不太讲理，属于为了「骑车」主动牺牲科学
