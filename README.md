## 🎨 画面

杂志封面风的海岸骑行：白鹈鹕戴着珊瑚色骑行帽、系着红围巾，骑一辆青绿色自行车沿海边前进，车篮里塞着两条鱼。背景有太阳、海鸥、帆船和两层视差云，左上角是 *PELICAN on wheels* 的封面排版。

## ✨ 亮点

- **踏板和腿是联动的**：用 JS 每帧算曲柄位置，再用两段式 IK（大腿 + 小腿）反解膝盖，脚一直踩在踏板上，不会穿模
- **围巾是程序生成的**：按正弦波实时生成飘带路径，不是循环帧
- **前后层次正确**：远侧腿和曲柄在车架后面，近侧在前面，链条、牙盘遮挡关系都对
- **很多小细节**：眨眼、喉囊随骑行晃动、尾羽轻摆、鱼尾扭动、后轮扬尘、地面速度线
- **照顾无障碍**：支持 `prefers-reduced-motion`，页面切到后台会暂停动画

## 🔍 可以挑刺的地方

- 鹈鹕的翅膀是直接搭在车把上的，算"手扶车把"但姿势略僵
- 速度线和车轮转速是分开写的，没有严格对上
