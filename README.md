# 骑自行车的鹈鹕

**提示词**：`Generate an SVG of a pelican riding a bicycle`

**形式**：单文件 HTML，内联 SVG，车轮和路面带 CSS 动画（开启"减少动态效果"时自动停止）。浏览器直接打开 `index.html` 即可。

![preview](preview.png)

## 亮点

- 鹈鹕坐在车座上、身体前倾，腿从身体下方伸到踏板上，脚蹼踩在踏板上，没有长在车架里
- 大嘴带下颌囊，颈上系一条红围巾
- 车轮转动，路面虚线向后滚动，有一点"正在骑"的感觉

## 翻车点 / 没做的事

- 没有手握车把：翅膀是向后上方张开的平衡姿势，没有伸到车把上
- 腿的位置是按曲柄角度手算的膝盖位置，看起来对，但不是真实的运动学
- 车座只露出一小条，属于"坐在上面"的糊弄式处理
